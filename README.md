### MineRepair

**Plataforma de gestión de reparaciones industriales**

Plataforma Full Stack orientada a la gestión de procesos de reparación industrial. Integra servicios backend, autenticación JWT, gestión de estados, PostgreSQL y automatización de despliegues.

**Características técnicas:**

- Integración de servicios frontend y backend.
- Autenticación y protección de funcionalidades mediante JWT.
- Gestión de procesos y persistencia de información.
- Contenedores Docker y automatización CI/CD.
